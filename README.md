# 📘 Facebook Follow Box

[![WordPress](https://img.shields.io/badge/WordPress-5.0%2B-blue.svg)](https://wordpress.org/)
[![PHP](https://img.shields.io/badge/PHP-7.4%2B-purple.svg)](https://php.net/)
[![License](https://img.shields.io/badge/License-GPL%20v2-green.svg)](https://www.gnu.org/licenses/gpl-2.0.html)

A beautifully designed WordPress plugin that adds a professional Facebook follow call-to-action section at the end of your posts and pages. Increase your social media followers with this customizable and mobile-responsive widget.

---

## ✨ Features

✅ **Beautiful Modern Design** - Professional appearance with smooth animations and hover effects  
✅ **Fully Responsive** - Perfectly adapts to all screen sizes (desktop, tablet, mobile)  
✅ **Easy Customization** - Change colors, text, and Facebook URL through WordPress admin  
✅ **Smart Display Control** - Choose to display on posts, pages, or both  
✅ **Lightweight & Fast** - Optimized code with minimal performance impact  
✅ **Translation Ready** - Prepared for multilingual websites  

---

## 🚀 Installation

1. **Download** the plugin file (`facebook-follow-box.php`)
2. **Upload** it to your `/wp-content/plugins/` directory
3. Go to your **WordPress Admin → Plugins**
4. Find **"Facebook Follow Box"** and click **"Activate"**

### Alternative: Upload via WordPress Dashboard

1. Go to **WordPress Admin → Plugins → Add New**
2. Click **"Upload Plugin"**
3. Choose the plugin file and click **"Install Now"**
4. Click **"Activate Plugin"**

---

## ⚙️ Configuration

After activation, go to **Settings → Facebook Follow Box** to configure:

| Setting | Description |
|---------|-------------|
| **Facebook URL** | Enter your Facebook page URL |
| **Custom Text** | Set your call-to-action message |
| **Background Color** | Choose background color (default: light blue) |
| **Show on Posts** | Enable/disable display on blog posts |
| **Show on Pages** | Enable/disable display on static pages |

Click **"Save Changes"** and you're done! 🎉
